# Документация для ассистентов

Любой ассистент, который берётся за Neon Nexus, **сначала читает эти файлы по порядку**:

1. [README.md](README.md) — что это за проект и как устроена папка
2. [WORKFLOW.md](WORKFLOW.md) — правила работы с Сергеем и передача задачи другому аккаунту
3. [DESIGN.md](DESIGN.md) — дизайн-система и читаемость
4. [DECISIONS.md](DECISIONS.md) — принятые продуктовые решения
5. [JOURNAL.md](JOURNAL.md) — что уже слито в `main`
6. [ROADMAP.md](ROADMAP.md) — текущее состояние и следующие шаги

После этого — блок «Статус» в открытом PR задачи (если он есть) и сам код.

Эта папка — рабочая память проекта. Решения из любого чата сюда записываются сразу. Строка журнала о PR пишется в том же PR до слияния; отдельный PR после слияния не открываем. Подробный визуальный гайд по-прежнему в [docs/DESIGN.md](../DESIGN.md) и [docs/design/styleboard.html](../design/styleboard.html); здесь — то, без чего нельзя продолжить работу с другого аккаунта.

## Проект

**Neon Nexus** (ранее **TON Nexus**) — Telegram Mini App: живой город, майнер, задания, реклама в городе, мини-игры (колесо, башня, арена), кабинет владельца.

- **Владелец продукта** — Павел: ставит требования.
- **Разработчик** — Сергей Фимин.
- **Репозиторий** — [Perspectivespace/ton-nexus](https://github.com/Perspectivespace/ton-nexus). После ребрендинга имя репозитория, пути на сервере и имя базы **не менялись**.
- **Тестовый домен** — `mytaskbot.de`.
- **Тестовый стенд** — каталог `/opt/taskbot_test/miniapp`, сервис API `ton-nexus-api.service` (за nginx). Каталог прода — `/opt/taskbot_prod`, ещё готовится.
- **Деплой теста** — только кнопка «Обновить тест» в кабинете владельца (`scripts/deploy-runner.sh`, alembic и рестарт API входят в прогон). Цель `prod` в деплое пока заглушена.

Секреты, адреса кошельков, IP сервера, пароли БД, ключи и seed-фразы в эту папку **не пишем**. См. [WORKFLOW.md](WORKFLOW.md).
