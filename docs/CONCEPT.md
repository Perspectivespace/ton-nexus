# TON Nexus / Task Forge — концепция продукта

> Единый источник правды по продукту (вместо разрастания Notion).
> Обновлять при принятых решениях владельца.

## В одной фразе

Telegram Mini App: **рынок заданий (TON)** + **личный майнер-контур** с усилением через двойную рулетку, daily, промокоды, уровни; вывод только вручную.

## Для кого

1. **Исполнители** — задания, майнер, daily, рулетки, вывод.
2. **Заказчики / амбассадоры** — создают задания в приложении, кладут бюджет награды.
3. **Владелец** — модерация, экономика, approve/reject выводов.

## Ядро MVP (делаем в начале)

| Модуль | Суть |
|--------|------|
| **Задания** | Заказчик создаёт; исполнитель выполняет → TON. Комиссия платформы. |
| **Майнер** | 1 слот. Сессия → сбор. Ежедневный ритуал. |
| **Усиление** | На экране майнера. Оплата → колесо типа → колесо успеха. Провал = **100% сгорание**. |
| **Типы усиления** | Мощность, Ёмкость, Ускорение, Удача, Стабильность |
| **Жетоны** | Фокус (подкрутка веса типа), Запрет (исключить тип на 1 попытку) |
| **Колесо наград** | Отдельно; якорь **+5% к успеху**; лимит спинов; без гарантии победы |
| **Daily check-in** | Привычка заходить |
| **Промокоды** | Акции / партнёры |
| **Уровни / XP** | Долгая прогрессия; не «TON за уровень» |
| **Вывод** | Заявка → **manual** approve владельцем |

## Не в MVP

- Игры (КНБ, блэкджек, турниры)
- Второй слот майнера (только later + soft-cap)
- Дома / бизнесы инвесторов (фаза 4+)

## Монетизация с запуска

| Источник | Как |
|----------|-----|
| Задания | Комиссия с бюджета / выплаты |
| Усиление | Sink TON (особенно burn) |
| Колесо наград | Лимит free-спинов; later билеты / Stars |
| Промо | Партнёрские кампании |
| Later | Stars → жетоны / +5% / билеты (не прямой +power) |
| Фаза 4+ | Дома: open fee + налог с прибыли + налог с зарплат |

## Экономика (жёсткие правила)

- Все коэффициенты в `economy_settings` (владелец без деплоя).
- 1 майнер на MVP; soft-cap мощности / ускорения / удачи.
- Донат = темп и agency, не безлимитный доход.
- Любой credit/debit → история баланса.
- Апгрейд только когда сессия не активна (рекомендация).

## Навигация UI

```
Главная · Задания · Майнер · Профиль
```

- **Главная** — баланс, XP, виджет майнера, быстрые входы.
- **Майнер** — полный пульт + **усиление** (не отдельный tab).
- **Задания** — лента / деталь / создание (заказчик).
- **Профиль** — daily, промо, вывод, реф.

## Дизайн (кратко)

Продуктовый custom UI, метафора **контур / реактор / instrument cluster**.  
Не шаблон Telegram miner / casino.  
Палитра: void `#070B12`, surface `#0E1522`, cyan `#22D3EE`, violet `#A78BFA`.  
UI на русском. Подробно — `docs/PROMPTS.md`.

## Дома инвесторов (future, не старт)

Инвестор открывает «дом», пользователи работают (смены/задания дома), зарплата из **пула дома**, инвестор — прибыль после налогов.  
Платформа: разовый open fee + % с прибыли + % с фонда зарплат.  
Пул не печатает TON из воздуха. Антифрод мультиакков. Только после стабильного MVP.
