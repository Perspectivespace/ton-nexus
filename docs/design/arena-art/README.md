# Превью арта «Арена-дистрикт» (PR #160)

Живописные слои webp, снято с локальной сборки, 2×, ширины 360 и 390.

- `arena-360-night-dark.webp` — ночь, тёмная тема
- `arena-360-day-light.webp` — день, светлая тема Telegram (без белой дымки)
- `arena-390-dusk-dark.webp` — закат, 390
- `arena-flat-360-night-dark.webp` — режим `?lite=1`
- `arena-390-night-dark-en.webp` — English
