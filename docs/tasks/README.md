# Задачи для ИИ-исполнителя

Здесь лежат брифы задач. Один файл = одна задача = один PR.

## Как работать

1. Прочитай `docs/HANDOFF.md` целиком (стек, инварианты, правила, дизайн, запреты).
2. Прочитай файл задачи, который тебе назвали (например, `docs/tasks/01-integrity-core-shadow.md`).
3. Создай ветку от актуального `main` с именем из брифа.
4. Сделай **только** то, что в разделе «Что сделать». То, что в «Не входит», — не трогай.
5. Прогони тесты (HANDOFF §3). Все должны проходить.
6. Открой **один** PR с заголовком из брифа. **Не мержи.**
7. В описании PR заполни чек-лист ниже. Ревью делает планировщик, сливает Сергей.
8. Если что-то в брифе противоречит коду — не угадывай: сделай по коду, а противоречие опиши в PR в разделе «Вопросы».

## Формат брифа

Каждый файл задачи содержит:

- **Цель** — зачем и что получится в итоге.
- **Контекст** — что уже есть в коде, с путями.
- **Модель данных и миграция** — таблицы, поля, номер миграции.
- **Логика** — правила, формулы, крайние случаи.
- **Настройки** — ключи `economy_settings` и значения по умолчанию.
- **API** — эндпоинты, права, тела запросов и ответов.
- **UI** — что видно и кому (или «ничего»).
- **Тесты** — какие обязательны.
- **Критерии приёмки** — проверяемый список.
- **Не входит** — что сознательно оставлено на потом.
- **Файлы**, **ветка**, **заголовок PR**.

## Шаблон описания PR

```
## Что сделано
<2–5 строк по-русски>

## Как проверить
<шаги; для UI — скриншоты 360 и 390 px>

## Не вошло / вопросы
<если есть>

## Чек-лист
- [ ] Один PR — одна задача, ничего «заодно»
- [ ] Прочитаны docs/HANDOFF.md и бриф задачи
- [ ] Все критерии приёмки из брифа выполнены
- [ ] Бэкенд: `python -m unittest discover -s tests` — зелёный
- [ ] Фронтенд: `npx vitest run`, `npx tsc -b`, `npm run build` — зелёные (если фронт менялся)
- [ ] Новая миграция с верным номером и `down_revision`; слитые миграции не тронуты; есть `downgrade`
- [ ] Деньги — только через `services/balance.py`; на денежные изменения есть тесты
- [ ] Время/месяцы — по МСК (`services/gameday.py`)
- [ ] UI: нет `backdrop-filter`, ≤ 19 бесконечных анимаций, статичная версия для `low-end` и «уменьшить движение», касания ≥ 44 px, скриншоты 360/390
- [ ] Нет секретов, IP, ID, ключей, паролей
- [ ] Не мержил, не делал force-push
```
