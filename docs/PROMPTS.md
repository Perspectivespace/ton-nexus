## 0. Мета-правило

```
TON Nexus — продуктовое решение, не сборка из UI-шаблонов.

Обязательно:
- Свой визуальный язык (контур / реактор / приборная точность)
- Иерархия и motion с функцией
- Mobile Telegram Mini App, UI на русском
- Dark void + cyan #22D3EE + violet #A78BFA

Запрещено:
- 3 stat-cards в ряд как единственная идея
- Miner/casino/tap templates, isometric coin farms
- Telegram blue, кислотный neon-grid
- Glass на каждой поверхности
- Dark patterns, скрытые шансы, «гарантия успеха»

Критерий: без логотипа экран ≠ «ещё один Telegram miner».
```

## 0.1. Как формулировать дизайн (anti-template)

### Сначала продукт
- Задача экрана за **3 секунды**
- **Одно** главное действие
- Роль: пульт / инструмент, не «игра с монетками»
- Анти-референсы

### Запреты сильнее пожеланий
| Запретить | Почему |
|-----------|--------|
| 3 одинаковые stat-cards | Частый AI-паттерн |
| Gradient + coin icon | Crypto-game 2022 |
| Glass everywhere | Дешёвый glass |
| Telegram blue / неон everywhere | Шаблон Mini App |
| Progress bar hero на всю ширину | Типично |
| Сетка 4–6 равных плиток | Admin template |
| Стоковые изометрические монеты | Клипарт |

### Одна метафора
**Контур / реактор** или **instrument cluster**. Без метафоры → cards + buttons.

### Иерархия
1. Hero → 2. Primary CTA → 3. Secondary → 4. Tertiary  
Glow только у статуса и главного CTA.

### Состояния
empty, loading, idle / running / ready, error / disabled (с причиной), успех / провал усиления.

### Motion с функцией
Idle — дыхание ядра; сессия — pulse; ready — вспышка; fail — короткий shake.

### Тон
Precision tool. «Готов к сбору», «Сгорает при неудаче». Без 🎉 и токсичного fail-copy.

### Каркас задания ИИ
```
1. Роль экрана (3 сек + одно действие)
2. Метафора (1 образ)
3. Данные/блоки (смысл, не layout)
4. Иерархия
5. Состояния
6. Палитра кратко
7. Жёсткие запреты
8. Уровень: fintech / pro tool
9. Критерий anti-template
10. Формат: концепт → иерархия → UI-spec → код
```

### Итерации (экономия токенов)
1. Концепт текстом  
2. Отбросить template  
3. Один экран в коде  
4. Точечная критика («убери 3 cards»), не «сделай красивее»

### Шпаргалка
| Шаблон | Продукт |
|--------|---------|
| Равные карточки | Один центр |
| Всё светится | Светится важное |
| Декор | Иерархия и числа |
| Один кадр | Система состояний |
| Crypto game | Pro tool |
| Универсальный layout | Из метафоры |

## 1. Эталон — HOME

```
Сделай high-fidelity прототип Home Telegram Mini App «TON Nexus».

ПРОДУКТ, НЕ ШАБЛОН:
Пульт оператора сети (Нексус), не idle-template, не casino kit, не card-pattern kit.

Контекст:
- Mobile 390×844, Telegram Mini App, safe-area
- UI язык: русский
- Tab: Главная (active) · Задания · Майнер · Профиль

За 3 секунды понятно:
1) баланс TON
2) уровень + XP
3) статус майнера и что нажать
4) куда дальше (задания / майнер)

Смысловые блоки (компоновку придумай сам):
- Баланс + уровень/XP
- Виджет майнера: Простаивает | Сессия | Готов к сбору + один primary CTA (Старт или Собрать)
- Быстрые входы: Задания, Майнер, Колесо наград
- 1–2 последних события
- Кастомный tab bar

Визуал: #070B12 #0E1522 #22D3EE #A78BFA #34D399 #F87171
Премиальный dark, precision, много воздуха. Motion только осмысленный.

Запрещено: crypto-dashboard grid, Telegram-blue, coin clipart, neon-grid, heavy glass everywhere.

Формат ответа:
1) Концепт оригинальности (5–8 предложений)
2) Иерархия
3) UI-spec
4) React + Tailwind, mock data, mobile-first
5) 3–5 motion notes

Критерий: без логотипа ≠ Telegram miner template.
```

## 2. Эталон — МАЙНЕР

```
HIGH-END экран «Майнер» Telegram Mini App «TON Nexus».

ПРОДУКТ, НЕ ШАБЛОН:
Пульт личного контура/реактора. Не upgrade shop, не 3 stat-cards, не green idle button.
Язык: instrument-cluster / reactor-core.

Навигация:
- Усиление ЖИВЁТ НА ЭТОМ ЭКРАНЕ (sheet/flow), не отдельный tab
- Tab: Главная · Задания · Майнер (active) · Профиль

Механики в UI:
- 1 майнер, 1 слот
- Статусы: Простаивает | Сессия идёт | Готов к сбору
- В сессии усиление disabled с причиной
- Статы: Мощность, Ёмкость, Ускорение, Удача, Стабильность — readout, не кирпичи
- CTA: Старт | Собрать + Усиление
- Усиление: цена + шанс + Фокус/Запрет → колесо типа → колесо успеха
- Провал = 100% сгорание (честный copy)
- Вторично: Колесо наград, история

Визуал:
- Hero = ядро + орбита сессии (не progress bar на всю ширину как центр)
- Усиление = «калибровка контура», связано с ядром
- Motion: дыхание idle; pulse сессии; вспышка ready

Состояния: Idle | Running | Ready | Upgrade prep sheet

Формат: концепт → z-order → UI-spec → React+Tailwind + overlay → motion notes
Критерий: precision product tool, не game-skin.
```
