# Языки приложения (i18n)

**Правило: каждая новая функция выходит сразу на двух языках — русском и английском.** PR, где игрок увидит
строку только на одном языке, не принимается: его остановит тест.

## Что поддерживается

- Языки: `ru`, `en`. Добавить язык — новая папка словаря и строка в `DICTS` (`frontend/src/i18n/core.ts`),
  код в `SUPPORTED` (`backend/app/core/i18n.py`).
- Язык первого входа — из Telegram (`language_code` в initData): `ru`, `uk`, `be`, `kk` → русский, остальные → английский.
- Игрок меняет язык в Профиле → «Настройки» → «Язык / Language». Выбор хранится на сервере (`users.lang`)
  и действует на всех устройствах. Пусто — язык Telegram.
- Кабинет владельца и инструменты команды остаются на русском.
- Текст, который написал игрок (реклама, названия заданий), показывается как есть.

## Фронтенд

- Словари: `frontend/src/i18n/ru/*.ts` и `frontend/src/i18n/en/*.ts`, по файлу на раздел (`common`, `home`, `city`…).
  Ключ плоский, с префиксом раздела: `"wallet.withdraw"`. Английский файл раздела типизирован ключами
  русского — забытый ключ не соберётся.
- В коде: `t("key")`, подстановки `t("key", { n: 3 })` → `{n}` в строке.
- Множественное число — формы через `|`: ru — `одна|несколько|много` (`"{n} день|{n} дня|{n} дней"`),
  en — `one|other` (`"{n} day|{n} days"`); вызов `tp("time.days", n)`.
- Числа и даты — только `fmtNum` / `fmtDate` из `@/i18n` (не `toLocaleString("ru-RU")`).
- `t()` зовут при рендере, не на уровне модуля: смена языка перемонтирует приложение (`LangRoot`),
  а константа модуля останется на старом языке. Для списков в модулях храните ключ, а не строку.
- Английский — короткий и «игровой»: на вывесках, табличках и кнопках он часто длиннее русского,
  поэтому новые надписи проверяйте на 360 и 390 px.

## Сервер

- Ошибку для игрока пишем в коде по-русски, как раньше, и сразу добавляем перевод в
  `backend/app/core/messages.py` (`EN`). Текст с подстановками — шаблоном: `"Минимум {min_ton} TON"`.
- Ответ об ошибке переводит обработчик в `app/main.py` по заголовку `X-Lang` (клиент шлёт его с каждым запросом);
  без заголовка текст уходит как есть. Подписи истории баланса — по `X-Lang`, иначе по языку игрока.
- Админка владельца, Касса и деплой остаются по-русски: их функции перечислены в `STAFF` в `tests/test_messages.py`.
- Бот отвечает на языке Telegram (`bot/texts.py`): ru / uk / be / kk — RU, остальным — EN.

## Тесты, которые это держат

- `frontend/src/i18n/i18n.test.ts` — в каждом языке все ключи, одинаковые подстановки, правильное число форм.
- `frontend/src/i18n/noCyrillic.test.ts` — кириллица в коде для игроков запрещена (кроме комментариев,
  словарей и кабинета команды).
- `backend/tests/test_messages.py` — у каждой ошибки для игрока (в `raise …`) есть английский перевод.
- `backend/tests/test_bot_texts.py` — у бота одинаковые ключи на обоих языках.
